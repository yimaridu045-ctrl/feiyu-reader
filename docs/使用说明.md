# 肥鱼阅读器 · 使用说明书

> 版本：2.0.0　|　作者：**yimaridu045-ctrl**（GitHub：https://github.com/yimaridu045-ctrl）　|　许可：MIT

---

## 一、这是什么

一个**免安装**的 Windows 本地阅读器，单文件 exe（约 250 KB），能读文本、文档、电子书和图片，还带**联网搜索**和**阅读进度记忆**。

- 不需要安装：解压即用，不写注册表、不装服务；
- 不需要额外运行时：只用 Windows 10/11 自带的 .NET Framework 4.8；
- 不联网也能用：只有「联网搜索」和 webp 之外的特殊格式才需要网络。

## 二、安装与启动

### 1. 首次使用

1. 下载并解压 `FeiyuReader-2.0.0-win-x64.zip` 到任意目录（例如 `D:\Tools\FeiyuReader`）；
2. 双击 **`肥鱼阅读器.exe`**。

> 建议：右键 exe → 发送到 → 桌面快捷方式；想换图标就右键快捷方式 → 属性 → 更改图标 → 选压缩包里的 `icon.ico`。

### 2. 三种打开文件的姿势

| 方式 | 操作 |
|---|---|
| 按钮 | 点顶栏「打开文件」 |
| 拖放 | 把文件直接拖进窗口任意位置 |
| 命令行 | `肥鱼阅读器.exe "D:\书\斗破苍穹.txt"` |

### 3. 做成"便携版"

程序默认把配置和历史写到 `%APPDATA%\肥鱼阅读器\`。想全部放在 exe 旁边：

```powershell
# 在 exe 同级目录建个 data 文件夹，然后设环境变量（用户级，永久生效）
setx FY_HISTORY_DIR "D:\Tools\FeiyuReader\data"
```

之后配置、历史、阅读位置都在这个目录里，整个文件夹拷走就能带走所有数据。

## 四、支持的文件格式

| 类别 | 格式 | 说明 |
|---|---|---|
| 纯文本 | txt、log、md、markdown | 直接读取 |
| 结构化文本 | json、xml、yml/yaml、ini/conf、csv/tsv | 按原样显示（不做格式化） |
| 字幕 | srt、ass、ssa、vtt、lrc | 按文本显示 |
| 源码 | py、js、ts、cs、cpp、c、h、java、go、rs、sql、sh、ps1、bat… | 按文本显示 |
| 网页 | html、htm、xhtml | 去脚本样式，只留正文 |
| Word | docx | 解压 OOXML 提取段落与换行 |
| 电子书 | epub、odt | epub 按文件顺序拼接各章 |
| 富文本 | rtf | 解析后取纯文本 |
| 图片 | png、jpg/jpeg、bmp、gif、webp、tif/tiff、ico、wmf、emf | webp 走系统 WIC 解码 |
| **不支持** | pdf、doc/xls/ppt（旧版二进制）、压缩包 | 会给出明确提示，不会乱码 |

**编码**：UTF-8（含 BOM）、GBK/GB18030、Big5、UTF-16 LE/BE 自动识别；识别错了可在顶栏「自动识别」下拉里手动指定，然后重新打开文件。

### 鼠标

| 操作 | 效果 |

| `PageUp` `PageDown` / 空格 | 翻屏 | 同上 |
| `Home` `End` | 跳到开头 / 结尾 | — |

- 字号：`A-` / `A+` 按钮，或 `+` / `-`，范围 12~48 px，自动记住；
- 主题：`深色` / `浅色` 按钮，或 `T`，自动记住。

### 阅读进度

正文滚动时会实时记录位置，**关闭窗口或切换到别的文件时保存**。下次打开同一文件会自动回到上次的位置。
每本书的位置单独记录（按"文件路径 + 大小"区分）。

## 六、最近阅读

- **不带参数启动**（双击 exe）时，如果之前读过文件，左侧直接显示「最近阅读」列表；
- 双击任意一条即可从**上次的位置**继续读；
- 最多保留 60 条，已被删除的文件会自动从列表里移除；
- 任何时候点左侧卡片右上角的 **「最近阅读」** 都能翻回来。

记录文件：`%APPDATA%\肥鱼阅读器\history.tsv`（可用记事本打开，格式：时间戳、位置、大小、类型、路径）。

## 七、图片查看

- 打开图片后顶栏按钮变为：**适应 / 1:1 / ‹ 上一张 / 下一张 ›**；
- 滚轮以光标位置为中心缩放（0.05× ~ 16×）；
- 左键拖动平移，双击在"适应窗口"和"实际大小"间切换；
- 左侧自动列出**同目录所有图片**，双击切换；
- 页脚显示：`文件名　图片　宽×高　第几张/共几张　大小　显示比例`。

> 支持 webp：程序会先尝试系统图形接口，失败再自动改用 Windows Imaging Component（WIC）解码。

## 八、联网搜索

### 怎么用

1. 顶部搜索框输入关键词，回车或点「搜索」；
2. 稍等 1~3 秒，左侧出现词条列表；
3. 双击词条 → 用系统默认浏览器打开该词条页面；
4. 想看完整网页搜索结果 → 点「浏览器」按钮，会**用百度搜索**这个词。

### 搜索结果来自哪里

| 顺序 | 来源 | 需要 Key |
|---|---|---|
| 1 | **百度百科词条** | 不需要 |
| 2 | 维基百科（百科无结果时兜底） | 不需要 |
| 3 | Serper（Google），结果最全 | 需要（可选） |

**为什么不是直接抓百度百科？** 百度官方对脚本请求全部拦截：搜索页返回 302 到验证页、词条页返回 403、旧开放接口无响应。
因此程序改用 Bing 的 `site:baike.baidu.com` 限定检索拿到真实词条，再解码跳转链接还原成 `baike.baidu.com/item/...` 地址。

### 想要更全的结果（可选）

到 <https://serper.dev> 注册（免费额度约 2500 次/月），把 Key 填进配置：

```ini
serperKey=你的Key
```

### 代理

如果所在网络需要代理：

```ini
proxy=http://127.0.0.1:7877
```

留空则跟随系统代理；连接失败时程序还会自动尝试 `7877 / 7890 / 7897 / 10809` 这几个常见本地端口。

## 九、配置文件

位置：`%APPDATA%\肥鱼阅读器\config.ini`（或 `FY_HISTORY_DIR` 指定目录）

| 键 | 默认 | 说明 |
|---|---|---|
| `fontSize` | 18 | 正文字号（12~48） |
| `theme` | light | `light` / `dark` |
| `width` / `height` | 1080 / 780 | 窗口尺寸（自动记住） |
| `proxy` | 空 | 联网搜索用的代理 |
| `serperKey` | 空 | 可选的 Serper API Key |
| `smoothScroll` | 0 | `1` = 启用像素平滑滚动（**实验性，边界可能不稳，见 `docs/scroll-notes.md`**） |
| `pos:<路径>\|<大小>` | — | 各文件的阅读位置（程序自动维护） |

改完保存后重新打开程序生效（字号/主题/尺寸无需手改，界面操作会自动保存）。

## 十一、常见问题

**Q：打开文本是乱码？**
A：在顶栏「自动识别」里手动选 `GBK` 或 `Big5`，然后重新打开文件。

**Q：docx / epub 打开是空的？**
A：可能不是标准格式（例如改了后缀的旧版 doc、加密文档）。docx 需要包含 `word/document.xml`。

**Q：pdf 为什么打不开？**
A：PDF 的文字层解析需要第三方组件，本程序只做"纯文本/文档/图片"，PDF 请先另存为 txt 或 docx。

**Q：搜索没有结果？**
A：先点「浏览器」用百度搜（浏览器里有 cookie，不会被拦）。应用内词条只覆盖"百科类"内容，冷门词、纯新闻类关键词可能确实没有词条。

**Q：搜索一直转圈或提示网络错误？**
A：多半是网络/代理问题。在 `config.ini` 里显式写 `proxy=` 你的代理地址试试。

**Q：滚动有点"生硬"？**
A：当前用的是控件原生滚动（稳定优先）。想试像素平滑可在配置里加 `smoothScroll=1`，但**边界处可能不稳**，不建议日常使用。

**Q：125% 缩放屏幕上字有点模糊？**
A：程序未声明 DPI 感知，由 Windows 位图放大。可以在 显示设置 里把该 exe 的"替代高 DPI 缩放行为"设为"应用程序"。

**Q：能同时开多个窗口吗？**
A：可以，每个窗口独立。历史文件同时写入时以最后一次关闭为准。

## 十二、从源码编译

只需要 Windows 自带的 .NET Framework 4.x（无需 Visual Studio / .NET SDK）：

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

产物：`dist\肥鱼阅读器.exe`。编译参数见 `build.ps1`（引用 `System.Windows.Forms`、`System.IO.Compression`、`System.Web.Extensions`，以及 WIC 用的 `WindowsBase`、`PresentationCore`、`System.Xaml`）。
